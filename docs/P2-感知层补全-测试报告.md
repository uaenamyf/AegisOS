## 7. 模块架构关系

```
perception/context/
    ContextManager ←→ memory/working    （读取会话上下文）
    TokenBudget     ←→ memory/compactor （超预算时触发压缩）

perception/reflection/
    ExecutionCritic → 纯算法批判
    OutputScorer    → 四维评分
    FeedbackLoop    → memory/reflection  （tag_outcome + record_reference）
```

### 与 memory/reflection 的区别

| | memory/reflection | perception/reflection |
|------|------|------|
| **对象** | 历史决策记忆（MemoryPacket） | 当前任务执行结果（runtime output） |
| **时机** | recall 重排序 / write 预评估 | Agent 执行完成后立即自评 |
| **产出** | 评分 float | FeedbackRecord → 写回 memory/reflection |
