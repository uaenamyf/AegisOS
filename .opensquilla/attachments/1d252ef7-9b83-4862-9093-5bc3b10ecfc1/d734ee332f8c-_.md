### 2.2 第二环节：我的总结与方向指引（近期 AI 大事 + 怎么上手）

听完你们的分享，我不讲抽象概念，直接盘最近（**2026 年 8 月**）真实发生、而且你们现在就能动手的事。先记住一句话：**大模型只是"大脑"，Harness（智能体框架）才是让它干活的"手脚"**——2026 年的竞争焦点，已经从"谁的模型更聪明"转向"谁能把模型可靠地跑起来、用起来"。

#### 2.2.1 近期最值得关注的 AI 大事（2026 年 8 月）

**（1）DeepSeek Harness v0.1（8/13 发布，MIT 开源）—— 今年最该跟的"智能体框架"**

- **干啥的**：过去让 AI 操作电脑的那套"手脚"——决定它能读哪些文件夹、能不能删东西、调用什么工具、对话记录存哪——基本是 Claude Code、Copilot 等海外工具说了算。DeepSeek 这次补上了**中国人自己维护的开源版**，对标 OpenAI Codex、Claude Code，主打编程和办公场景的 AI 生产力工具。
- **核心理念**："一切皆插件"（everything is a plugin）。模型、工具、技能、会话、沙箱、文件系统、甚至 UI 全是插件，挂在共享上下文里，能自由替换、组合，**不用改主体代码**。
- **四种运行模式**：标准（通用任务）/ 代码聚焦（写代码指挥多个应用）/ 创意（实验自定义工具）/ 最小（隔离安全测试）。
- **咋用（实测命令）**：
  ```bash
  npx @deepseek-ai/dsh web      # 无需 clone，直接起 Web UI
  # 浏览器打开 http://127.0.0.1:3080
  ```
  想从源码玩：
  ```bash
  pnpm install && pnpm run build && pnpm dsh web
  ```
- **热度**：发布 24 小时冲到 8 万+ Star，围绕 `dsh-plugin` 主题的仓库已超 1300 个。

**（2）DeepSeek V4 Pro 正式版（8/13 全量上线）—— 模型本身也变强了**

- **干啥的**：DeepSeek 旗舰模型正式版，重点强化 **Agent 能力**。在编程智能体基准 DeepSWE 上得分从预览版 12.8 飙到 62.7。
- **咋用**：和我们实验室现有链路一致——通过 API 调用即可（我们后端已接模型，可按需切换）。写代码、跑 Agent 都够用。

**（3）阿里 Qwen3.8-Max 开放权重（8/13）—— 国产旗舰首开权重**

- **干啥的**：阿里首次把 Max 级旗舰模型**对外开放权重**，意味着你能把模型下载下来自己部署、私有化跑。展示过连续自主编程约 16 天、独立复现并改进论文、2000+ 轮经营虚拟电商等极限测试。
- **咋用**：从 HuggingFace / ModelScope 拉权重，配合 vLLM / Ollama 本地起服务；我们实验室 5090 能跑量化版。

**（4）Meta Muse Glimmer 30B（8/10 开源，Apache 2.0）—— 单卡就能跑的本地 Agent**

- **干啥的**：300 亿参数、专为**本地 Agent 工作流**优化的开源模型。4-bit 量化后 <20GB，能塞进 24/32GB 显存（就是我们 5090 的显存量级），单卡离线跑 Agent。自带规划、工具调用、自我检查、故障恢复。
- **咋用**：`ollama run muse-glimmer` 或 vLLM 部署；适合在实验室服务器上做本地 Agent 实验，不依赖外部 API。

**（5）微软 MagenticLite 全栈开源（含 Fara 1.5 权重）—— 连"应用 + 框架 + 模型"全给了**

- **干啥的**：微软首次把智能体应用的全部组件（应用、Harness、所有模型权重）一次性全开源。小模型 Fara 1.5（4B/9B/27B）在浏览器任务上 72% 成功率，超过 OpenAI Operator。说明"小模型 + 精细工程"也能干翻旗舰。
- **咋用**：GitHub 拉 MagenticLite，本地跑端侧智能体，适合研究"模型—工具联合设计"。

> 💡 **我的判断**：2026 年 8 月这波的核心不是"又有个更强的模型"，而是 **"模型 + Harness"双开放**。开源模型中国下载占比已超美国（HuggingFace 2026 春报 41%）。对你们的意义：**本地、免费、可改**的 AI 能力已经成熟——别再只当 API 调用者，要学会部署和组装。

#### 2.2.2 这些大事对你的"用法"意味着什么（动手路线）

- **路线 A（最推荐）：自己的模型 + DeepSeek Harness 跑通一个 Agent**
  ```bash

  ```
 做一个"能读你文件夹、跑命令"的小助手。
- **路线 B：本地部署一个开源模型**
  - 用 Ollama / vLLM 把 Qwen3.8 或 Muse Glimmer 跑在 5090 上，体验"私有化 AI"。
- **路线 C：复现一个大事件**
  - 比如用 Harness 的"代码聚焦模式"自动改一个 GitHub 项目；或跑通 MagenticLite 的端侧 Agent。

> ⚠️ **注意**：这些工具都在快速迭代（开发者预览版，可能不兼容改动）。**先跑通官方示例，再改**，别一上来魔改源码。

#### 2.2.3 工程能力——把上面的工具真正用起来

- **Python + PyTorch**：必备，模型训练和推理都靠它。
- **本地部署与推理**：会把自己的模型 / 应用跑起来

- **复现 > 看教程**：一个能跑通的 GitHub 项目，比看 10 篇收藏的文章更有用。

## 三、新学期计划与短期目标

> **关键认知**：目标不写下来 = 没目标；目标不可衡量 = 自我感动。**用 SMART 原则**。

### 3.1 什么是好的短期目标（SMART）

- **S（Specific，具体）**：不是"学 AI"，是"用 LangChain 搭一个能查本地文档的问答 Agent"。
- **M（Measurable，可衡量）**：能用"跑通 / 准确率 / 产出几个文件"来判断。
- **A（Achievable，可达）**：2 周能做完，不是 2 个月的大饼。
- **R（Relevant，相关）**：和你方向 / 毕设 / 项目相关。
- **T（Time-bound，有期限）**：明确到"9 月 15 日前"。


### 3.2 我给你们的方向性建议（长期主线）

**主线**：以"做一个能解决真实问题的 AI Agent / 应用"为牵引，反向补齐基础。

1. 本学期末，每个人至少有 **1 个能演示的 AI 小项目**。
2. 至少 **1 次**在组会上完整讲清楚（教学相长）。
3. 尝试 **Multi-Agent / 上线部署**，为后续竞赛、毕设铺路。
